## Description
Stop pasting messy web pages into your AI chat.

Copy for AI turns any web page into clean, structured Markdown with one click – no menus, ads, cookie banners or footnote clutter. Headings, lists, tables, links and code blocks are preserved, so ChatGPT, Claude, Gemini or Perplexity get exactly the content they need and nothing else.

HOW IT WORKS
• Click the icon → "Copy this page" (or press Alt+Shift+C, or right-click → Copy page for AI)
• Paste into your AI chat. Done.

FEATURES
✓ Readability-grade extraction: article text only, boilerplate removed
✓ Selection mode: copy just the paragraph you highlighted
✓ Word & token counter with context-window warnings (GPT-4o, Claude)
✓ Prompt templates: Summarize, Explain simply, Key points & action items, Q&A context – or plain content
✓ Optional title + source URL header so your AI can cite the page
✓ Toggle links and images on/off
✓ Keyboard shortcut and right-click menu
✓ Dark mode

PRIVACY
Everything runs locally in your browser. No account, no analytics, no servers. Pages never leave your machine. The only network call is looking up your Pro license key by email if you buy one and lose it; pasted keys are verified offline.

Works with: ChatGPT, Claude, Gemini, Perplexity, Copilot, Poe, Mistral, local LLMs – anything that accepts text.

## Single purpose description (for review)
Converts the content of the current web page (or selected text / open tabs) into Markdown text and copies it to the clipboard for use in AI chat tools.

## Permission justifications
- activeTab: read the current page's content when the user clicks the extension, uses the shortcut or the context menu.
- scripting: inject the extraction script into the active tab on user action.
- storage: save user preferences, templates and (Pro) local copy history.
- contextMenus: provide "Copy page for AI" / "Copy selection for AI" right-click items.
- clipboardWrite: place the generated Markdown on the clipboard.
- offscreen: write to the clipboard from the keyboard shortcut / context menu (service workers have no clipboard access).
- notifications: confirm a successful copy when triggered via shortcut/context menu (no popup visible).
- tabs + <all_urls> (optional, requested at runtime): the Pro "All tabs" feature needs to enumerate and read the other open tabs. Only requested when the user first uses that feature.
