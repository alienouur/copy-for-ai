FAQ

Does it work with Claude and Gemini?

Yes. The output is plain Markdown text, so it works anywhere you can paste text.

Does the extension send my pages anywhere?

No. Extraction and formatting happen entirely inside your browser. The only network request is validating a Pro license key with Lemon Squeezy, if you buy one.

How accurate is the token count?

It is an estimate (about 4 characters per token for English) – within roughly 10–15% of what OpenAI and Anthropic tokenizers report.

Can I use Pro on multiple computers?

Yes, a Pro key can be activated on up to 3 browsers.
